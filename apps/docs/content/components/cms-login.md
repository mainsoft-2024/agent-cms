For the CMS's own sign-in (`createAuth`, see [Sign-in](/docs/sign-in)). Sign in with a passkey, single sign-on, or email and password with a 6-digit code; the first admin with the setup code; accepting an invitation; password reset.

Changing how someone signs in asks the person to confirm it is them first (password or passkey, valid 10 minutes). Korean text is included.
