- **Renamed to `@mainsoft/agent-cms`** and published to npmjs.com with provenance: `npm i @mainsoft/agent-cms` needs no `.npmrc` or token. Import paths change scope only.
- The admin screens install with the shadcn CLI: `npx shadcn add <registry-url>/cms-shell.json`. Files go to `components/cms/`, and screens that need other screens bring them along.
- The screens work with either shadcn base, Radix or Base UI.
