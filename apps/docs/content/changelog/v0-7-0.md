- **Anonymous MCP read:** `createCmsHandler({ mcp: { anonymous: "read" } })` lets agents use `/mcp` without a key. They get the read tools only and see published documents of collections anyone may read. Off by default.
- Releases are published with npm trusted publishing and provenance; no npm token is stored anywhere.
- These docs moved to agent-cms itself.
