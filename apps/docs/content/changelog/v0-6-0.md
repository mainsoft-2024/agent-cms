Breaking changes come with steps in [Upgrade to 0.6 and 0.7](/docs/upgrade-0-6).

- Collections require `visibility`; errors have fine codes and one shape on every transport; `fields` updates are a JSON Merge Patch; gaps moved out of the library (`onSearchMiss`).
- ETag and `If-Match`, conflicts that carry the other copy, autosave, line-by-line merge.
- Agent change review: accept or revert each block an agent wrote.
- `patch_document`, `diagnose_document`, `bulk_documents`; citation ids and the `<cms-document>` envelope for answers.
- Draft preview links, bulk actions, API key expiry and an audit log.
- `init`, `doctor`, `migrate`, `add` in the CLI; nine admin screens to copy into your app, in English and Korean.
