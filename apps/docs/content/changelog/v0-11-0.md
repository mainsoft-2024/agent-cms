title: "0.11.0: Vercel Blob, image sizes, section order"
date: 2026-11-20
---

What was left of the media library and the editor. Schema version 5: run `npx agent-cms migrate apply`, then `npx agent-cms add --update` for the screens. See [Upgrading to 0.11](/docs/upgrade-0-11).

- **Vercel Blob.** `vercelBlobStorage({ token, access })` from `@mainsoft/agent-cms/storage-vercel-blob`. Browsers upload straight to Blob; private stores are read through signed links. A file goes up in one request on this kind of store. Checked against real public and private stores. [Media library](/docs/media-library#vercel-blob)
- **Image sizes.** `media.transforms: sharpTransforms({ presets })` from `@mainsoft/agent-cms/image-sharp`: named sizes at `?size=card`, made on first request, with limits and the original as the fallback. [Media library](/docs/media-library#image-sizes)
- **Focal point.** Click the part of a picture that must stay in view; `fit: "cover"` sizes are cropped around it.
- **Replace a file at its address.** Same id and path, new content, checked before it takes the old one's place.
- **`media.stripMetadata`.** Photos lose their location, time and device data in the browser before they are sent.
- **Uploads carry on after a reload.** Choosing the same file again sends only the missing parts.
- **Editor: section order.** Cards for the `##` sections, moved by dragging or with arrow buttons.
- **Editor: the preview follows the text**, and a click on a block in the preview selects its lines.
- **Changed:** on wide screens the editor fills the window's height and scrolls inside itself. Pass `className` with the height that is left if your admin has its own top bar.
- **Changed:** `StorageAdapter` gained three optional members (`multipart`, `settle`, `size` in `presignPut`). Existing adapters need no change.
