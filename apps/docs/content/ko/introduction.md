agent-cms는 **지금 쓰는 웹 앱 안에서** 돌아가요. 별도 서버도, 새 데이터베이스도 필요 없어요. 사람은 앱에 복사해 넣은 어드민 화면에서 편집하고, AI 에이전트는 도구로 같은 문서를 읽고 써요. 블로그, 릴리스 노트, 도움말 센터, 사내 문서, 공지 게시판처럼 CMS가 할 일이면 어디든 쓸 수 있어요.

## 무엇이 들어 있나요

- **테이블 하나에 여러 컬렉션.** 모든 컬렉션이 같은 `cms_*` 테이블을 써서, 컬렉션을 더해도 마이그레이션이 필요 없어요. 컬렉션마다 타입이 있는 `fields`(zod), 카테고리, 슬러그, 문서 규칙 검사가 있어요.
- **버전.** 저장할 때마다 전체 스냅샷이 남아요. 초안, 게시, 게시 취소, 숨김, 되돌리기가 돼요. 오래된 내용으로 저장하면 충돌이 나고, 편집기가 두 내용을 줄 단위로 합쳐요.
- **에이전트도 편집자.** 도구 목록 하나를 MCP, CLI, REST 세 가지 길로 써요. 앱 안의 에이전트에는 같은 도구를 함수로 줘요. 에이전트는 섹션 단위로 고치고, 저장 전에 초안을 점검하고, 사람은 에이전트가 고친 블록을 하나씩 검토해요.
- **답하기 좋은 검색.** 한국어를 이해하고, `cms://docs/install#tables` 같은 인용 id가 붙은 섹션을 돌려줘요.
- **내가 가진 어드민 화면.** shadcn으로 앱에 복사하는 화면이에요. 앱의 부품으로 만들어져요.
- **안전한 기본값.** 컬렉션마다 `public` 또는 `internal`을 정해요. API 키는 해시로만 저장되고 범위와 만료일이 있어요. 게시, 삭제, 거부된 요청은 감사 로그에 남아요.

## 이 사이트

이 페이지들도 agent-cms 문서예요. 조직 멤버는 어드민에서, 에이전트는 API 키로 편집하고, 어떤 에이전트든 키 없이 MCP로 읽을 수 있어요. [에이전트로 읽기](/agents)를 보세요.
