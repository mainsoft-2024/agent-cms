## 아직 안 한 것

- **블록 편집기(ab-rich 나머지)**: BlockNote(MPL-2.0 core만, xl-* 금지) 연결, 우리 Block ↔ BlockNote 변환기(`cms-blocks-convert.ts`), 사용자 블록(미디어, 알림 상자, 문서 링크, HTML, 원문), 바뀌지 않으면 저장하지 않기, 한국어 IME e2e, 지연 로딩, `editor: "markdown"` 옵션.
- **ab-p1 공통**: 알림(toast)과 실행 취소, 확인 창 통일, 단축키(`cms-keys.ts`), `aria-live`·`aria-sort`, 상대 시각 title, 동작 줄이기.
- **ab-p2 편집기 공통**: `/` 메뉴, 이미지 붙여넣기 올리기, 오프라인 사본(`cms:draft:<c>/<slug>`), 저장 상태 표시, 떠날 때 경고.
- **ab-p3 화면**: 게시 전 점검 창, 문장·단어 단위 버전 비교.
- **ab-p4 미디어**: 여러 개 선택과 일괄 이동·태그·삭제·zip(`GET /assets/zip`), 필터(미사용, 대체 텍스트 없음)와 정렬, 저장 용량, 크롭 미리보기, 올리기 트레이, 올리기 전 크기 줄이기.
- **ab-p5 휴대폰**: 키보드 위 서식 줄, 미디어 고르기 시트.
- **ab-htmldoc 화면**: 편집기의 HTML 문서 모드와 변환 창.
- **제안 카드**: 편집기에서 제안을 보고 적용·거절하는 카드 (서버와 REST는 끝).
- 문서 사이트: 새 기능 안내 페이지(`agent-files`)만 썼다. 컴포넌트 페이지와 올리기 안내(UPGRADE-0.15)는 릴리스 때.

## 3차 (2026-11-21): 블록 편집기를 자체 구현으로 교체, 한 칸 화면

사용자 지적: WYSIWYG인데 좌우로 나뉘어 좁음. 외부 편집기 코드를 쓰지 말고 우리 방식으로 새로 쓸 것.

한 것:
- BlockNote·Mantine 의존성 제거. `cms-block-editor.tsx`(화면), `cms-blocks-convert.ts`(마크다운 ⇄ 블록), `cms-blocks-inline.ts`(글자 서식, 커서 계산)를 새로 씀. 지킴 테스트(`src/parts.test.ts`)가 편집기 라이브러리 import와 의존성을 거절.
- 블록 보기는 한 칸(최대 780px, 페이지 폭과 비슷). 미리보기는 "새 창에서 미리보기"로 따로 띄우고 고치는 대로 바뀜(저장 없이). 마크다운 보기에서는 "옆에 미리보기"를 켜고 끌 수 있음.
- 전체화면 편집(2026-11-22): 본문 줄의 "전체화면" 버튼, ⌘/Ctrl+Shift+F, Esc로 끝냄(글 입력 중이거나 메뉴·창이 열려 있으면 Esc는 그쪽 몫). 사이드바·머리·댓글을 덮고, 필드는 얇은 상단 줄의 "필드" 버튼으로 펼침(필드 오류가 생기면 저절로 펼치고 버튼에 빨간 점). 입력하는 동안 상단 줄이 흐려지고 마우스를 움직이면 돌아옴. "모니터 전체 쓰기" 버튼은 브라우저 전체화면(Fullscreen API). 휴대폰에서는 버튼이 없음(이미 화면 전체). 브라우저 테스트 1개.
- 마크다운 단축 입력(`## `, `- `, `1. `, `[] `, `> `, `> [!tip] `, `---`, ```` ``` ````, `**굵게**`, `*기울임*`, `~~취소~~`, `` `코드` ``), 서식 막대(블록 종류 바꾸기 포함), 링크 창(⌘K, 위험한 주소 거절), 블록 손잡이(끌어 옮기기, 메뉴: 바꾸기·복제·위/아래·마크다운으로 복사·삭제), 블록 선택(Esc, Shift+↑↓, 끌어서, ⌘A 두 번), 마크다운으로 복사·붙여넣기, 이미지 붙여넣기·끌어 놓기 업로드, 자체 되돌리기 기록(300단계, 타이핑은 묶음), 알림 상자 블록(종류 선택), 할 일 체크, 코드 블록(언어, Tab 들여쓰기), 이미지 블록(대체 텍스트 칸, 바꾸기). 표·접기·2단·HTML은 그려진 모양으로 보이고 더블클릭이나 Enter로 원문 편집.
- 손대지 않은 블록은 원래 글자와 블록 사이 빈 줄까지 그대로 씀: 저장소의 마크다운 파일 전부가 바이트 단위로 같게 돌아오는 테스트.
- 상태 줄에 단어 수와 읽는 시간.
- 코드 안에 백틱이 여러 개인 경우(```` `` ` `` ````)를 파서가 읽게 고침(`codeSpan`).
- 브라우저 테스트 7개(`e2e/blocks.spec.ts`): 열기만 해서는 저장 안 됨, 단축 입력·서식 막대·Enter·Backspace·되돌리기, / 메뉴·원문 블록·블록 선택과 삭제·되돌리기, 키보드와 손잡이 메뉴로 옮기기, 새 창 미리보기가 타이핑을 따라옴, 한국어 입력(휴대폰 포함), 게시 전 점검.
