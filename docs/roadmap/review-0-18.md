# 0.18.0 리뷰에서 남긴 것

0.18.0은 리뷰를 11차까지 돌린 뒤 배포함. 리뷰 반복 기준을 바꿔서(최대 3차, P0/P1만 고침, 여러 조건이 겹쳐야 생기는 것은 끝) 아래 항목은 고치지 않고 남김. 각 항목은 다음 버전 후보.

- [남음] `beforeChange` 훅이 `prev.published`·`prev.autosave`를 인용해 오류를 던질 때, 그 사본에서만 숨긴 필드는 가림 판단에 들어가지 않음 (훅이 숨긴 값을 오류 문구에 넣고, 그 필드가 현재 사본에서는 보이고 옛 사본에서만 숨겨져야 생김).
- [남음] 편집기가 수정 권한을 잃은 뒤(`receipt`): 이미 열려 있던 선택 상자·미디어 고르기 창, Base UI 다중 선택 체크박스, 확장 슬롯 setter가 막히지 않음. 대기 중인 자동 저장 재시도와 복원 배너 동작도 실행 시점에 다시 막아야 함. 일반 저장 receipt는 제출한 버퍼가 아니라 화면 버퍼를 저장된 것으로 표시함.
- [남음] 웹훅 이벤트 묶음 체크박스는 aria-checked로 섞임 상태를 알림 (primitive의 indeterminate 아님).
- [남음] Node 어댑터 역압 테스트는 시간 기반(일시 정지 후 실패)이라 쓰기 대기 상태를 직접 확인하지는 않음.
- 알려진 한계는 `UPGRADE-0.18.md`의 "Known limits"에 있음.
