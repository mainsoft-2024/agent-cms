# 블록 편집기: 노션 수준 작업 (0.19.0)

## 한 것

- 손잡이 끌기(포인터 이벤트): 따라오는 그림, 파란 선, 가장자리 자동 스크롤, Esc 취소, Alt 복사, 편집기 밖에 놓으면 아무것도 안 함, 여러 블록 함께.
- 옆에 놓아 2단·3단(단은 독립 블록), 빈 단은 저장해도 유지, 마지막 블록이 빠진 단은 사라지고 한 단만 남으면 풀림.
- 토글: 열고 닫기, 안으로 넣기, 닫힌 토글 위에 잠시 머물면 열림, 마지막 자식 아래 왼쪽으로 끌면 밖으로.
- 중첩 목록: Tab / Shift+Tab(노션처럼 뒤 형제가 따라감), 빈 중첩 항목 Enter는 한 단계 위로, 목록 항목 아래 문단·토글(빈 줄 뒤 들여쓰기).
- 표: 칸 단위 편집, Tab·Enter·화살표, 행·열 추가, 열 정렬·삽입·삭제 메뉴, 칸에서 ⌘/로 같은 메뉴(키보드).
- 그림 캡션과 대체 텍스트 줄, 상자 선택(여백에서 끌기), 손잡이 메뉴 검색과 여러 블록 바꾸기, ⌘⌥0·2·3·4–8, 휴대폰의 블록 옵션 버튼.
- 리뷰 1차(관점 셋)에서 나온 P0 2개·P1 전부 고침: 표 칸의 백틱, 중첩 코드의 탭, 목록 아래 문단 저장, 옛 들여쓰기 재사용, 붙여넣기 뒷부분 위치, 빈 단, 0부터 번호, 단 경계 Backspace, + 뒤 Esc, Shift 클릭 기준점, 편집기 밖 놓기.

- 리뷰 2차(변경분)의 P1 7개 고침: 짝 없는 백틱이 표 칸을 삼킴, 번호 목록의 들여쓰기 기준(표시 너비), 들여쓴 한 항목 옮기기, 줄 맨 앞 붙여넣기에서 자식 유지, Tab이 실패하면 기본 동작, 고정 막대 위에 놓기, 0부터 번호 표시. 리뷰는 규칙대로 2차에서 멈춤.

## 아직 안 한 것

- 마크다운에 담을 곳이 없는 것: 글자·배경 색, 단 너비 조절, 그림 크기, 블록 링크(고정 id). 하려면 문법 확장이나 별도 메타데이터가 필요.
- 손잡이 메뉴의 "다른 문서로 옮기기", "블록 링크 복사".
- 휴대폰에서 끌어서 옮기기(지금은 메뉴의 위로·아래로).
- 표 행·열 끌어서 순서 바꾸기, 끌어서 여러 행 늘리기.
- 상자 선택 중 자동 스크롤.
- 여러 블록에 걸친 글자 선택(지금은 블록 선택으로 대신).
- `UPGRADE-0.6.md`처럼 옛 문서 일부를 새로 쓰기(손댄 블록) 했을 때 원문과 달라지는 경우가 남아 있는지 다시 확인(review-0-18.md).
